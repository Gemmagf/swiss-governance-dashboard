🚀 API Endpoints (FASE 4)

FastAPI REST backend ready for deployment. Deploy locally or to AWS Lambda/Heroku.

Available Endpoints

GET /predict

Indicator forecasts with uncertainty bands

/predict?indicator=co2&lang=ca

POST /simulate

Policy impact simulation

{"policies": {"carbon_tax": 0.5}, "year": 2032}

GET /explain

SHAP explanations with factors

/explain?indicator=co2

GET /anomalies

Anomaly detection alerts

/anomalies?indicator=co2

GET /model-card

Model metadata and accuracy

/model-card?indicator=co2

GET /health

Health check endpoint

/health

GET /info

API information

/info?lang=ca

🚀 Deploy Locally

python src/api/main.py
# API available at http://localhost:8000
# Docs at http://localhost:8000/docs
